I’ve always focused on the practical side of security. Most of my work revolves around defensive security and backend engineering, and setting up <span class="skill-highlight">Security Monitoring</span> pipelines, building practical <span class="skill-highlight">Threat Detection</span> rules, and digging through deep <span class="skill-highlight">Log Analysis</span> to see how attacks actually unfold. When analyzing adversary behavior, I map techniques against the <span class="skill-highlight">MITRE ATT&CK</span> framework. In practice, that means querying telemetry in SIEMs like <span class="skill-highlight">Splunk</span> using <span class="skill-highlight">SPL</span> or writing <span class="skill-highlight">KQL</span> rules in <span class="skill-highlight">Microsoft Sentinel</span>, running <span class="skill-highlight">Event Correlation</span> to cut through the noise for <span class="skill-highlight">Alert Triage</span> and hands-on <span class="skill-highlight">Incident Response</span>. I spend a lot of time doing <span class="skill-highlight">Network Traffic Analysis</span> and low-level <span class="skill-highlight">Packet Analysis</span> because packets never lie. I use <span class="skill-highlight">Wireshark</span> to inspect streams, <span class="skill-highlight">Nmap</span> for mapping out networks, and <span class="skill-highlight">Scapy</span> when I need to craft or manipulate raw packets to test detection limits. My primary daily environment is <span class="skill-highlight">Linux (Ubuntu)</span> alongside <span class="skill-highlight">Windows</span>, where I automate workflows using <span class="skill-highlight">Bash</span> scripts, and I mostly use <span class="skill-highlight">Python</span> for automation and tool development.

When I build tools and detection platforms, I focus on simple, solid architecture rather than bloated stacks. I build fast, clean <span class="skill-highlight">REST APIs</span> using <span class="skill-highlight">FastAPI</span>, with particular care given to <span class="skill-highlight">API Security</span> and proper <span class="skill-highlight">Authentication</span>. For data storage and caching, I rely on <span class="skill-highlight">PostgreSQL</span> with straightforward <span class="skill-highlight">SQL</span> queries and <span class="skill-highlight">Redis</span> for quick lookups. And to make sure what I build doesn't break, I track everything with <span class="skill-highlight">Git</span> and <span class="skill-highlight">GitHub</span>, test endpoints using <span class="skill-highlight">Postman</span>, and write unit tests with <span class="skill-highlight">Pytest</span>.
