**xentinel** is a real-time SOC simulation built around Linux telemetry, log pipelines, alerting, and a small monitoring dashboard.

The goal is to understand what actually happens between an event being generated and an analyst seeing an alert.

**Stack:** Python · Flask · Linux · SOC · Telemetry
