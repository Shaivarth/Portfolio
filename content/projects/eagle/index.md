**Eagle** is an image forensics and metadata extraction tool.

Drop an image into Eagle and it instantly extracts its EXIF data to reveal pinpoint location coordinates right where it was taken, along with all hidden EXIF metadata and camera settings in seconds.

**Stack:** Python · EXIF Analysis · Geolocation · OSINT · Security
