Xentinel

Xentinel is a real-time SOC simulation platform built around Python telemetry, attack detection pipelines, and live SIEM-style threat visualization.

It generates simulated security and authentication telemetry, processes events through detection engineering rules, and provides an interactive dashboard for SOC analyst workflows.

Stack: Python · Flask · Linux · SOC · Telemetry · SIEM · MITRE ATT&CK
