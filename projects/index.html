cool things i've built

A selection of security, backend, and systems projects I’ve worked on.

Eagle

Drop an image into Eagle and it instantly rips open its EXIF data to drop a pin-point location right where it was taken, with other useful details.

Xentinel

Xentinel is a real-time SOC simulation platform that generates security telemetry, detects threat activity, and visualizes attacks on a live SIEM dashboard.

Hexora

hexora inspects files of any kind without executing them and performs static analysis to identify potentially suspicious characteristics.

Arpex

arpex is an arp spoofing detection system that scans local network traffic, tracks arp mappings, and send alerts on a dashboard.
